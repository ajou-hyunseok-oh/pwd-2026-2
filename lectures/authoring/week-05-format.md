# 05주차 기준 포맷 — 06 적용

사용자의 최신 지시는 **05주차의 디자인·본문 정리 형식 + 제공된 PDF의 제목·내용·실습**이다. 두 기준을 함께 지킨다.

- 표지: 2026학년도 2학기·6주차, 05와 같은 주차형 제목 묶음과 `LECTURE 06`.
- 본문: `authoring.css`의 제목·리드·정의/세부 설명 위계·여백·글꼴·표·그림·코드 형식.
- 내용: PDF 제목·학습 순서·설명·코드·표의 모든 행과 열·도식 요소/연결·실습 요구사항 보존. 새 개념과 예제, 임의 제목을 추가하지 않음.
- 준비: `06/scripts/prepare-assets.py`로 이미지·합성 도식·코드·표·원문을 먼저 추출. 합성 도식은 필요한 전체 요소를 함께 추출하며 원본 슬라이드 제목과 반복 머리말은 분리.
- 배치: `06/scripts/lesson.py`에서 각 페이지에 맞게 설명+그림, 코드+표, 설명+코드+도식 등 명시적으로 선택. 원본의 전체 페이지 좌표는 강제하지 않음.
- 검사: 내용의 누락·대체 검사와 05 형식 검사, 발표·인쇄·모바일·육안 검토를 함께 진행. 기존의 50장 재구성본과 페이지 전체 SVG 표시본을 재사용하지 않음.

정의의 개수나 강의 장수 때문에 내용을 바꾸지 않는다. 업데이트 제안은 본문과 분리한다. 05의 기존 원본과 07~13의 골격은 변경하지 않는다.
