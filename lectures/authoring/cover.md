# 강의 표지 공통 형식

적용 대상은 강의 덱의 첫 화면 `cover`다. 챕터 표지와 본문 제목에는 이 형식을 적용하지 않는다.

## 01~04에서 확인한 작성 사례

| 사례 | 상단 작은 문구 | 큰 제목 | 부제 | 우하단 |
| --- | --- | --- | --- | --- |
| [01](../01/index.html) | 2026학년도 2학기 실전웹서비스개발 | 실전 웹서비스개발 – 1주차 | 강의소개 | LECTURE 01 |
| [02](../02/index.html) | 동일 | 실전 웹서비스개발 – 2주차 | 웹 페이지의 구성 요소와 렌더링 원리 | LECTURE 02 |
| [03](../03/index.html) | 동일 | 실전 웹서비스개발 – 3주차 | JavaScript와 TypeScript의 문법을 통한 실행 흐름과 코드 구조 이해 | LECTURE 03 |

공통 요소는 왼쪽 정렬, 세로 중앙의 제목 묶음, 큰 제목과 그 아래 작은 회색 부제, 넉넉한 빈 공간, 우하단의 `LECTURE NN`이다. 학기·과목명과 주차형 제목은 01~03의 공통 요소이며, 04에는 없다. 두 사례를 구분해 아래의 선택 규칙을 정한다.

## 이번에 정한 선택 규칙과 정보 역할

**한 회차를 하나의 덱으로 제공할 때는 01~03의 주차형을 기본으로 사용한다.** 한 회차를 독립된 주제별 덱으로 나눌 때는 04의 주제형을 사용한다. 05는 하나의 회차 덱이므로 주차형이다.

| 정보 역할 | 주차형 `weekly` | 주제형 `topic` |
| --- | --- | --- |
| 상단 문구 | 학년도·학기·공식 과목명 | 생략 |
| 큰 제목 `h1` | `실전 웹서비스개발 – N주차` | 해당 덱의 강의 주제 |
| 부제 | 이번 회차의 강의 주제 | 큰 제목을 구체화하는 학습 범위 |
| 우하단 회차 | `LECTURE NN`, 두 자리 숫자 | 동일 회차의 각 덱에 같은 번호 |

- 현재 학기·과목명은 `2026학년도 2학기 실전웹서비스개발`이다. 저장소명이나 다른 과목명을 추측해 넣지 않는다.
- 영문 상단 문구는 `Practical Web Service Development · Fall 2026`, 주차형 제목은 `Practical Web Service Development – Week N`이다. 학년도·학기·주차는 한국어와 일치시킨다.
- 부제에는 주제나 범위를 나타내는 짧은 명사형 구문을 쓴다. 내용이 길면 자연스럽게 줄바꿈하며, 글자 수나 한 줄 배치를 강제하지 않는다.
- 상단 문구에 `LECTURE NN`을 붙이지 않는다. 회차 표기는 우하단에 한 번만 둔다.
- 학습 목표 목록·설명 본문·코드·출처 목록·제작 안내·다음 내용 예고를 표지에 추가하지 않는다. 학습 목표와 상세 범위는 해당 본문에서 다룬다.

## 공통 시각 형식

[02의 CSS](../02/lecture.css)와 [03의 CSS](../03/lecture.css)를 주차형 기준으로 사용한다. 01의 부제 크기 차이와 04의 주제형 제목 크기는 기존 사례로 보존한다.

| 요소 | 공용 작성 값 |
| --- | --- |
| 배경·글꼴 | 공용 `--wd-paper`, Noto Sans KR 계열, 공용 본문색·회색 `--wd-muted` |
| 여백·정렬 | 위 2.2rem / 좌우 3rem / 아래 1.8rem, 왼쪽 정렬, 제목 묶음 세로 중앙 |
| 제목 묶음 | 최대 폭 52rem, 회차 표기는 묶음 밖에 배치 |
| 상단 문구 | .72rem / 굵기 700 / 자간 .06em |
| 주차형 제목 | 3rem / 굵기 760 / 행간 1.14 / 자간 -.03em, 상단 문구 다음 간격 1rem |
| 주제형 제목 | 2.8rem / 굵기 760 / 행간 1.2 / 자간 -.035em |
| 부제 | 1.32rem / 굵기 650 / 행간 1.45 / 회색, 제목 다음 간격 1.2rem |
| 회차 표기 | .7rem / 굵기 700 / 자간 .1em, 오른쪽 3rem / 아래 1.8rem |

표지는 `.wd-lesson-cover`, 제목 묶음은 `.wd-lesson-cover__content`, 상단 문구는 `.wd-lesson-cover__eyebrow`, 큰 제목은 `.wd-lesson-title`, 부제는 `.wd-lesson-cover__subtitle`, 회차 표기는 `.wd-lesson-source`를 사용한다. `data-wd-cover="weekly"` 또는 `"topic"`으로 형식을 명시한다. 본문용 `.wd-slide-lead`와 챕터용 `.wd-lesson-eyebrow`를 표지에 사용하지 않는다.

모바일에서는 공용 슬라이드의 한 열 흐름을 유지한다. 표지 좌우 여백은 1rem, 제목은 2.2rem으로 줄이고 한국어 단어 단위 줄바꿈을 허용한다. 회차 표기는 내용 다음 오른쪽에 배치해 긴 제목과 겹치지 않게 한다. 발표·인쇄에서는 우하단 위치를 유지한다.

## 05에 적용한 내용

1. 상단: `2026학년도 2학기 실전웹서비스개발`
2. 큰 제목: `실전 웹서비스개발 – 5주차`
3. 부제: `React Framework의 이해`
4. 우하단: `LECTURE 05`

기존 주제 `React Framework의 이해`를 부제로 유지하고, 잘못된 과목명과 상단의 중복 회차 표기를 제거한다. 생성 원본은 [lesson.py](../05/scripts/lesson.py)이며 HTML·번역·슬라이드 맵을 함께 생성한다. 2번째 이후 슬라이드의 내용은 이번 표지 수정 범위에 포함하지 않는다.

## 확인 기준

- 첫 화면에 선택한 표지 형식, 제목 한 개, 부제 한 개, 회차 표기 한 개가 있는가?
- 주차형의 학기·공식 과목명·주차·회차가 서로 맞고 KO/EN이 일치하는가?
- 제목·부제의 위치와 굵기·색·간격이 위 기준을 따르는가?
- 한국어·영어의 발표·인쇄·모바일에서 자연스럽게 줄바꿈하고 잘림이나 겹침이 없는가?
- 원본에서 재생성한 뒤에도 수정 결과가 유지되는가?
