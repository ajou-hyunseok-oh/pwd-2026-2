보관 중인 원본 PDF의 AI 역사·언어 모델·프롬프트 내용을 바탕으로, 2025~2026년 Claude·Codex 개발 방식의 변화를 반영해 확정한 순서다. 시기는 주요 발전·확산 시기를 뜻하며, 명세·테스트·Git 등 기존 기법의 최초 등장 연도를 뜻하지 않는다. 서로 겹치는 시기의 발전은 학습에 필요한 개념 순서로 묶었다.

챕터 제목과 범위, 76개 본문의 순서를 유지하면서 확정 문단을 발표용 정의와 글머리표로 작성했다. 본문에는 구성 요소의 역할과 관계를 설명하고, 자료는 그 설명을 확인할 사례로 연결한다. 확정 문단과 개별 원본 추출본은 별도 보존한다.
