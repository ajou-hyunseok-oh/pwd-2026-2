메모리 저장의 한계

완료된 요청의 변경 데이터도 서버 재시작 후 소멸

메모리 저장 - 실행 중인 서버 프로그램 안에 데이터 보관
  • 프로세스(process)는 실행 중인 프로그램 · 메모리는 이 실행 동안 유지
  • 시드(seed)는 서버 시작 시 불러오는 초기 JSON 데이터
  • 여러 클라이언트는 같은 서버의 데이터를 공유해도 재시작 후 신규 맛집 소멸
  • DB의 영구 저장은 서버 재시작 후에도 변경 데이터를 보존하는 방식
데이터6주차 저장 위치
초기 맛집(시드)restaurants.json → 메모리
새로 등록한 맛집서버 메모리 · 재시작 후 소멸
제보·좋아요브라우저 내 저장소(localStorage)
