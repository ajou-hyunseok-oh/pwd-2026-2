06주차 클라이언트 코드 리뷰 — 화면·설명 대응 재검토, 2026-10-16

범위와 기존 검토의 한계
표지 포함 8장 유지. 기존 Express PDF 강의 27장과 원본 클라이언트 소스는 수정하지 않는다.
이전의 배치·번역 검사 통과는 화면과 설명이 맞는다는 근거가 되지 않았다. 3장의 공통 레이아웃, 5장의 선택 버튼, 6장의 메뉴 입력, 7장의 데이터 종류가 어긋났고, 2장과 8장은 스크린샷이 뒷받침하는 범위를 넘어 설명했다. 이전의 대응 검토 완료 판정은 이 기록으로 대체한다.

1. 표지 — 해당 없음
스크린샷·본문 코드가 없는 표지. 2026학년도 2학기·6주차·LECTURE 06 확인.

2. React 프로젝트의 실행 구조 — 설명의 근거 구분
홈 화면은 root 검색이나 프로젝트 파일 구조를 보여주지 않았고, 코드에서도 root 검색이 빠져 있었다. root 검색·존재 검사·App 연결을 실제 main.tsx에서 함께 발췌했다. 홈 화면은 App의 렌더링 결과로 명시하고 Header·HomePage·footer 전체를 포함한다. 파일·폴더의 역할은 별도 표에서 설명한다.

3. 공통 레이아웃과 페이지 라우팅 — 캡처 교체
기존 상세 본문에는 설명한 Header·footer가 없었다. #/list의 전체 App 화면으로 교체해 Header·목록·footer를 동시에 표시한다. 목록의 자세히 보기 링크는 카드의 상세 링크 코드에, 본문 선택은 App의 Routes에 대응한다.

4. 목록과 카드의 컴포넌트 분리 — 일치
전체 목록의 카드 3개가 RestaurantList의 map에 대응한다. 각 카드의 이름·분류가 RestaurantCard의 name·category 표시에 대응한다. 목록을 순회하는 부모와 항목을 표시하는 자식의 역할 관계를 유지한다.

5. 조회 데이터와 화면 상태 — 캡처 상태 오류 수정
기존 사진에는 한식 카드 1개와 활성화된 전체 버튼이 함께 있었다. React가 필터 결과를 바꾼 뒤 CSS의 300ms 색상 전환이 끝나기 전에 촬영한 것이 원인이다. hover를 해제하고 실제 CSS 전환 완료 후 촬영하도록 수정했다. 한식 버튼의 배경 rgb(102, 126, 234), 전체 버튼의 흰 배경, 카드 1개를 모두 확인한다.

6. 제보 폼의 저장 흐름 — 캡처·설명 범위 교정
기존 사진에는 메뉴 입력란이 잘려 있었다. 실제 추천 메뉴 입력란에 김치찌개, 제육볶음을 입력한 근접 화면과 동일 제출의 완료 화면으로 교체했다. 문자열 분리 코드와 저장 성공 후 상태 전환으로 설명 범위를 맞췄다. 저장 결과의 recommendedMenu가 김치찌개와 제육볶음의 배열인지 확인한다. 캡처에 없는 입력 검증 과정을 화면이 보여주는 것으로 설명하지 않는다.

7. 서비스 함수의 데이터 접근 — 다른 데이터 화면 교체
기존 왼쪽은 submissionAPI의 제보 목록, 오른쪽은 restaurantAPI.getRestaurants의 맛집 조회여서 데이터 종류가 달랐다. 동일 getRestaurants를 사용하는 AdminPage의 맛집 표로 교체했다. 송림식당·별미떡볶이·Sogo 3개와 API 조회 결과를 대조한다. 현재 localStorage 접근과 향후 서버 API 대체는 표에서 구분한다.

8. 서버가 맡을 데이터 책임 — 근거 화면 교체
인기 화면 하나만으로 맛집·제보·좋아요의 공유 책임을 설명할 수 없었다. 같은 URL을 연 두 독립 브라우저의 제보 목록으로 교체했다. 실제 폼으로 저장한 A의 제보는 1건, 저장소가 독립된 B는 0건이다. 긴 무작위 ID 열은 잘라 내고 제보 내용·제보자·상태 영역을 사용한다. 현재 브라우저별 저장의 한계와 앞으로 서버에서 공유할 데이터 책임을 구분한다. 서버 권한 검사·집계·승인 일괄 처리를 현재 구현된 기능으로 표현하지 않는다.

재생성 경로
lesson.py와 capture-app.cjs에서 수정한 뒤 원본 앱을 실행해 다시 캡처했다. 실제 소스의 코드 발췌와 화면의 원본 파일 해시를 생성기에서 대조한다. slide-map.json은 각 장의 스크린샷·캡션·코드 발췌를 함께 기록한다. 생성 HTML만 수정하는 방식은 사용하지 않는다.
