# 06주차 작성 계약

- 디자인과 본문 정리 형식: 05주차. 공통 표지·챕터·제목·여백·정의와 세부 설명·표·그림·검정 배경/녹색 Consolas 코드 블록을 사용한다.
- 제목·본문·학습 순서·코드·도식·표·실습: `materials/[PWD Week4] Node.js Express 프레임워크를 이용한 웹 서버 개발.pdf`. 개념을 추가하거나 다른 사례로 교체하지 않는다.
- 현재 표지: `2026학년도 2학기 실전웹서비스개발`, `실전 웹서비스개발 – 6주차`, 원본 주제, `LECTURE 06`. 원본의 2025년·4주차 표기는 현재 강의 표지에 사용하지 않는다.
- 이미지·합성 도식·표·코드를 `scripts/prepare-assets.py`로 먼저 추출한다. 도식의 내부 요소·라벨·화살표·비율은 보존하며 페이지 전체의 기존 배치를 복사하지 않는다.
- `scripts/lesson.py`에서 원본 요소를 슬라이드별 배치로 조합하고 `scripts/build-slides.py`로 HTML·번역·제목표·슬라이드 맵을 생성한다.
- 원본 비교표는 모든 행·열을 유지한 HTML 표로 만든다. 원본 코드는 값·API·예제·주석을 보존하며 서식 조정만 허용한다.
- 원본의 실습 목표·필수 구현·Foodmap 사례·기존 URL을 유지한다. 추가 실행 예제로 원본 실습을 대체하지 않는다. 미지정 마감일이나 새 저장소는 추정하지 않는다.
- 원본 보존 검사와 05 형식 검사, 실제 발표·인쇄·모바일 및 육안 검토를 모두 수행한다. 기존의 50장 재구성본과 페이지 전체 SVG 표시본은 현재 작성 기준이 아니다.
- 원본의 기술 업데이트 검토는 별도 제안으로 유지한다.
