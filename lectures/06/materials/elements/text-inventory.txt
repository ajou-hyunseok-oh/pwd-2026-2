PAGE 10 HTTP/HTTPS
p10-u01 [heading] HTTP = HyperText Transfer Protocol
p10-u02 [●] 하이퍼텍스트를 빠르게 교환하기 위한 프로토콜
p10-u03 [●] 서버와 클라이언트의 사이에서 어떻게 메시지를 교환할지를 정해 놓은 규칙
p10-u04 [●] 각 HTTP 요청을 독립적으로 처리 이전 요청의 정보를 연결·기억하지 않음(Stateless: 무상태)
p10-u05 [●] 필요한 맥락은 매 요청마다 함께 전송
p10-u06 [●] 특징
p10-u07 [○] 확장성: 어떤 요청이든 아무 서버가 처리 가능.
p10-u08 [○] 장애 격리: 한 서버가 내려가도 세션 날아가지 않음.
p10-u09 [○] 같은 요청을 다른 서버가 받아도 결과 동일
p10-u10 [heading] HTTPS = HyperText Transfer Protocol Secure
p10-u11 [●] 웹 브라우저와 웹사이트 간의 데이터 통신을 암호화하여 보안을 강화한 프로토콜
p10-u12 [●] HTTP가 데이터를 암호화하지 않고 전송하여 해킹에 취약했던 문제를 해결하기 위해 개발

PAGE 15 라우팅(Routing)
p15-u01 [●] 서버가 받은 요청을 실제 처리할 핸들러 함수에 연결하는 과정

p15-u09 [○] 롤백/재처리가 쉽게(운영/장애 대응)
