# 05 형식 배치에 사용할 원본 요소

`prepare-assets.py`가 원본 PDF에서 텍스트·코드·표·그림을 먼저 추출한다. `manifest.json`은 각 요소의 원본 페이지·좌표·식별자를 연결한다. 좌표는 추출과 원문 대조에 사용하며 최종 슬라이드 배치를 고정하지 않는다.

- 원본 비트맵: 원래 이미지와 투명도 마스크를 결합해 보존. 내용·비율·라벨을 수정하지 않음.
- 합성 도식: 원본 벡터·텍스트·이미지·아이콘을 함께 4배율로 렌더링. 웹서비스 구조, HTTP 요청/응답 비교, REST 예시, 미들웨어 흐름, 폴더 트리 포함.
- 웹서비스 구조: 도식과 무관하게 추출 영역에 겹치는 페이지 제목만 제외. 요청/응답·Network·JSON·모든 원본 이미지와 화살표는 유지.
- 코드: 원본 녹색 코드 구역의 문자·주석·예제를 파일로 추출. 05 코드 스타일로 표시.
- 표: 원본 비교표의 모든 행·열을 추출해 HTML 표로 표시.
- 원문 단위: 문장을 새로 쓰지 않고 줄바꿈을 연결하며 굵은 제목·세부 항목의 위계를 05 형식으로 표시.

27개 원본 페이지와 210개 원문 단위, 19개 그림 배치, 9개 코드 파일, 3개 비교표를 준비했다. 여러 PDF 이미지 객체가 한 합성 도식에 함께 들어갈 수 있다. 모든 학습용 이미지 배치는 `check-source.py --pdf`에서 대조한다.
