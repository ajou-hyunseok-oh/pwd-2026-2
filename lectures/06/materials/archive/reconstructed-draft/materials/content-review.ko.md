## 학습 순서 검토

함수·배열·객체·Promise·async/await는 03, React 상태·Effect는 05의 선수 범위다. 새 서버 API는 06의 해당 개념에서 설명한다. `requires` 자동 검사는 내부 순서를 확인하며 문장 의미 검토를 대신하지 않는다.

| 구간 | 선행 위험과 처리 |
| --- | --- |
| Node.js·I/O | require 학습 전에 파일 모듈 예제를 사용하지 않고 일반 흐름 사용. 이벤트 루프는 기학습 타이머·콜백 사용 |
| HTTP·REST | JSON 문법·변환 뒤에 REST 표현 표 배치. 메서드 의미 다음에 멱등성 배치 |
| Express 시작 | 프로젝트→CommonJS→서버 순서로 모듈 규칙 선행 학습 |
| 미들웨어·본문 | 라우트 기본→next·순서→JSON 파서→검증→오류 처리 |
| 원본 17–20 | MVC/TDD에 필요한 라우팅·입력·비동기 오류를 먼저 배치한 뒤 계층과 테스트 적용 |
| 계층 예제 | 모델→서비스→컨트롤러→Router. 주입 객체·발췌 조건을 라벨에 표시하고 전체 소스 제공 |
| 브라우저 연결 | 환경 설정·배포·CORS 뒤에 fetch 요청. React는 05의 기학습 범위만 참조 |

- Node.js 24.22.0에서 실행 예제 11개 테스트 통과.
