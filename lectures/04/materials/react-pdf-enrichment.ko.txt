정확성 보정
- 원본 6쪽의 명령형 코드는 jQuery가 아닌 document.createElement 등의 DOM API. 실제 jQuery의 .appendTo/.text/.on으로 교체.
- 원본 parseInt('Click me') + 1은 NaN. 별도 숫자 count를 0으로 초기화하고 매 클릭 1 증가.
- 반대편 React도 count=0에서 시작하고 같은 문구·동작을 제공. 명령형/선언형을 오답/정답으로 표시하지 않음.
- 표시 코드는 comparison-examples.jsx의 마커 구간에서 추출. 실제 버튼도 그 모듈을 실행하여 코드/결과 불일치 방지.
- host·useState(0)·JSX는 코드를 읽는 데 필요한 뜻만 캡션으로 설명. API 상세 실습 없음.
- 1/2/3세대의 배타적 교체 모델 대신 공존하는 개발 방식의 확장으로 정리.
- Virtual DOM은 브라우저 DOM의 전체 복제본이 아니라 메모리의 UI 표현. 구조는 설명에 필요한 하위 트리.
- 17번의 출력 DOM은 그림의 section → p/ul → li 구조와 실제로 일치. 품절 두 행 삭제, 6→4 변경, 나머지 행 유지 표시.
- 비교는 Render 작업의 일부. Commit의 DOM 변경과 브라우저 스타일/레이아웃/페인트를 구분.
- jQuery가 전체 DOM을 반드시 다시 만들거나 React가 항상 더 빠르다는 단정 제거.
- 19번은 MutationObserver로 텍스트 변화와 버튼 노드 유지 관찰. 벤치마크나 속도 수치를 제시하지 않음.
- 배치 업데이트는 여러 상태 갱신을 다루는 후속 주제로 남겨, 단일 클릭 예시의 성능 근거로 확대하지 않음.
