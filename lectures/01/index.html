02

웹서비스 개발 개요

웹서비스란 무엇인가?

기술 표준 정의 (W3C Web Services Architecture, 2004)

네트워크에서 상호운용 가능한 시스템 간 상호작용을 지원하도록 설계된 소프트웨어 시스템

“A Web service is a software system designed to support interoperable machine-to-machine interaction over a network.”

W3C: 팀 버너스리가 중심이 되어 1994년 설립된 웹 기술 국제 표준화 공동체

웹서비스의 일반적 의미와 형태

넓은 의미(일반적 정의)

  • 인터넷을 통해 제공되는 모든 형태의 서비스
  • 웹 브라우저나 앱을 통해 사용자에게 콘텐츠·기능을 제공

종류

  • 정적 웹페이지(Static Web Page)
  • 동적 웹페이지(Dynamic Web Page)
  • 웹앱(Web Application)

정적 웹페이지(Static Web Page)

  • 서버에 미리 생성된 HTML·CSS·JavaScript·이미지 파일을 저장
  • 사용자 요청 시 저장된 파일을 그대로 전달
  • 서버가 요청마다 페이지 내용을 새로 생성하지 않음
  • 콘텐츠 변경 시 파일을 다시 생성하거나 수정하여 배포
  • JavaScript 화면 동작과 외부 API 사용 가능

Ex) 회사 소개 페이지, 포트폴리오, 문서 사이트, GitHub Pages

동적 웹페이지 (Dynamic Web Page)

  • 사용자·시간·저장된 데이터에 따라 표시 내용이 달라지는 웹페이지
  • 서버가 요청에 맞는 HTML을 생성하여 전달하는 방식
  • 브라우저가 API로 데이터를 받아 화면 일부를 변경하는 방식
  • 데이터 변경 내용을 페이지 새로고침 또는 화면 갱신으로 반영

Ex) 게시판 목록, 쇼핑몰 상품 페이지, 검색 결과, 날씨 조회

웹앱(Web Application)

  • 웹 브라우저를 통해 사용자가 특정 작업을 수행할 수 있도록 만든 응용 소프트웨어
  • 입력·검색·편집·저장 등 사용자 동작에 따라 화면과 상태가 변경
  • 필요한 데이터를 서버의 API에 요청하고, 처리 결과를 응답받아 화면에 반영
  • 전체 페이지를 다시 불러오지 않고 필요한 부분만 갱신 가능

Ex) Gmail, Google Docs, Figma, Notion, NotebookLM

클라이언트-서버 모델

네트워크에서 서비스를 요청하는 클라이언트와 요청을 처리해 응답하는 서버가 역할을 나누는 구조
