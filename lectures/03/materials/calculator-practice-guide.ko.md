# 3주차 실습 · 공학용 계산기

HTML·CSS가 제공된 계산기에 TypeScript 숫자 검증과 연산 함수를 작성합니다. 완성 후에는 호출 순서와 상태 변화를 추적하여 3주차 개념을 코드로 설명합니다.

## 화면과 동작

| 구분 | 기능 |
| --- | --- |
| 입력 | 숫자 `x`, 이항 연산의 숫자 `y`, 연산 선택 |
| 기본 연산 | 덧셈·뺄셈·곱셈·나눗셈·제곱·제곱근 |
| 공학 함수 | sin·cos·tan·ln·log₁₀, DEG/RAD 선택 |
| 결과 | 계산식, 결과 또는 오류 메시지 |
| 이력 | 성공한 최근 계산 5개, 이력 삭제 |

자유 수식을 해석하는 계산기가 아니라 선택한 연산에 인수를 전달하는 구조입니다. 함수별 입력과 결과, 실행할 함수의 선택 과정을 직접 확인할 수 있습니다.

## 학생 구현과 제공 코드

| 구분 | 대상 |
| --- | --- |
| 학생 구현 | `src/validation.ts`의 `parseNumber` |
| 학생 구현 | `src/operations.ts`의 `subtract`, `multiply`, `divide`, `square`, `sqrt` |
| 제공·읽기 | HTML·CSS, DOM·이벤트 처리, 입력·결과 타입, 공학 함수, 이력 클래스 |
| 강사용 | `solution/`의 완성 함수, 같은 화면에서 실행하는 `/demo` |

## 진행 순서

1. 완성 예제에서 `12 / 3`, `√9`, DEG `sin(30)`, `12 / 0` 실행.
2. 코드의 입력·반환 타입 확인 후 정상·오류 결과 예측.
3. 문자열 검증 → 사칙연산 → 제곱·제곱근의 세 단계 구현.
4. 타입 검사와 정상·실패·경계 테스트 실행.
5. 계산 흐름 추적과 순수 함수·캡슐화·Strategy 구조 설명.

실행 명령과 정확한 입력 규칙은 [프로젝트 안내](../calculator/README.md), 제출할 읽기 기록은 [리뷰 기록지](../calculator/review.md)에 있습니다. 수업 운영과 해설은 [강사용 안내](../calculator/instructor.md)를 사용합니다.
