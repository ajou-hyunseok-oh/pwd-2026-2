실행 환경과 한계
- React 기초 코드는 React 컴포넌트 예제. Props가 필요한 예제는 라벨에서 입력 계약 명시.
- 라우팅·데이터·서버 예제는 Next.js App Router 기준. root layout과 DB/권한 함수는 별도 필요.
- CSR/SSR/Hydration은 API 구조 예시이며 실행 환경과 초기 HTML 조건을 설명.
- use client는 모듈 경계이며 서버에서 초기 HTML이 생성될 수도 있음을 설명.
- 서버→클라이언트 Props의 직렬화는 React 지원 값 기준이며 JSON으로 한정하지 않음.
- 원본의 과거 빌드 환경이나 Effect 설명을 그대로 사용하지 않고 공식 문서와 대조.
- 주제 30은 브라우저 지연·입력 검사만 수행하고 실제 저장하지 않음.
- 주제 31은 Server Function 입력·권한·저장 구조. useActionState 연결 시 결과 객체를 맞추도록 명시.
- 주제 32의 saveStock은 Promise<boolean> 또는 reject. 성공/실패 검증은 모의 비동기 응답 사용.
- Next.js 프로젝트 실행, 실제 DB·권한·캐시 통합, 배포 검증은 수행하지 않음.
