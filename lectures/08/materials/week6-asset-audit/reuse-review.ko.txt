10쪽: 세션·토큰·OAuth를 같은 분류로 나열하므로 현재 개념 구조에 채택하지 않음.
11쪽: 세션 요청 시퀀스 재사용 우선. 오른쪽 잘린 라벨 확인.
12쪽: 쿠키 헤더 코드 재사용 우선. 학습 단계에 따라 속성 분리.
13쪽: 세션 저장 위치 그림, 설정 객체, 짧은 세션 객체 예를 각각 추출.
14쪽: 토큰 요청 시퀀스의 골격 활용. JWT 검증과 저장 위치 표현 수정.
15쪽: JWT 구조 그림·JSON·서명 식을 분리. 서명 식은 필수 자료에서 제외.
16쪽: 비교표의 무효화 관점만 발췌. 전체 이분법 표는 그대로 사용하지 않음.
17쪽: OAuth 참여자·코드 흐름의 대안 원본. 토큰 응답과 브라우저 경유를 명확히 해야 함.
18쪽: 3.4~3.6 공통 시퀀스 원본. state 검사·PKCE 변환·조건부 ID 토큰 표현 보강.
19쪽: 보안·운영 챕터 표지. 현재 챕터 디자인으로 대체되어 재사용 대상 아님.
20쪽: 공격 정의 텍스트만 있음. 공격 그림·실행 코드 없음. Directory Traversal은 현재 60장 범위 밖.
21쪽: 환경·비밀정보 관리 텍스트만 있음. 설정/환경 분리 설명의 근거.
22쪽: 토큰 수명·보관·로그아웃 텍스트만 있음. 고정 만료 권장 수치와 네트워크 탭 은폐 문구는 제외.
23쪽: 쿠키 속성·외부 스토어·Timeout 텍스트. SameSite=Non 오타와 항상 전송 표현 교정.
24쪽: 로그/모니터링 텍스트. 실제 로그 행·대시보드·지표 그림 없음.
25쪽: 실습 챕터 표지. 별도 실습 세션 범위.
26쪽: Passport 개념과 짧은 API 표기만 있음. 완전한 로그인 구현 코드 없음. 현재 이론 필수 자료에서 제외.
27쪽: 국외/국내 제공자 표 2개. 이름 중심으로 발췌 가능.
28쪽: Google 콘솔 URL만 있음. 콘솔 화면 캡처가 아님.
29쪽: Naver 개발자 URL만 있음. 설정 화면 캡처가 아님.
30쪽: 이전 실습 과제와 제출 기한·URL. 이번 이론 자료로 복사하지 않음.
31쪽: Q&A 표지. 재사용할 개념 자료 없음.

내용 교정 확인 근거

- PKCE S256 변환과 verifier 검증: https://www.rfc-editor.org/rfc/rfc7636.html
- OAuth 위에 추가되는 OIDC와 ID 토큰: https://openid.net/specs/openid-connect-core-1_0.html
- SameSite=None; Secure 및 브라우저의 쿠키 전송 조건: https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie
- cookie.maxAge·sameSite·secret 설정의 실제 의미: https://expressjs.com/en/resources/middleware/session/

조사 시점의 후속 제작 범위
원본 후보를 곧바로 덱에 삽입하지 않고 위 대응표의 학습 범위·오류 수정 조건을 적용. 새 애셋 검토는 원본에 없는 해시·솔트, 계정 연결, 소유자/RLS, 운영 상태, 브라우저 경계, DB 환경 분리·복구 등에 한정.
기존 이미지에 섞인 한국어는 EN 모드에서 별도 번역이 필요하므로, 라벨 수정이 많은 시퀀스는 공용 편집 가능한 도식으로 재구성하는 편이 후속 비용이 낮음.
원본 그림 자체에 별도 제작자·라이선스 출처가 기재되지 않은 경우 원저작자는 확인되지 않은 상태로 기록하고, 출처를 임의로 만들지 않음.
실습 라이브러리 선택, 제공자 콘솔 조작, 과제 기한·제출 방식은 이번 이론 자료 조사에서 제외.
